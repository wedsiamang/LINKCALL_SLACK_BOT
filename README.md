# LINKCALL_SLACK_BOT

A Slack bot that returns the URL linked to a keyword when mentioned.

> I'm studying Spring Boot after passing Java Silver. I developed this by running AI-generated (Claude) code and reading through it to understand each piece; the "Code Walkthrough" section below is my own explanation of what each class does.

### Background
Built to solve the "where's that link again?" problem that comes up on Slack.
You can pull up a link straight from Slack instead of digging through bookmarks.

### Tech Stack
- Java 17
- Spring Boot 【verify: parent version in pom.xml】
- Slack Bolt SDK (Socket Mode)
- Spring Data JPA / H2 Database (file mode)

> Generated the project on `https://start.spring.io/`, then added Slack Bolt manually.
> H2 file mode persists data without any external DB setup.

### Prerequisites
- Java 17 / Maven
- Permission to add an app to your Slack workspace

### Features
| Command | Action |
|---|---|
| `@bot register keyword URL` | Register a URL |
| `@bot keyword` | Return the URL |
| `@bot delete keyword` | Delete it |
| `@bot list` | Show all registered entries |

In a DM, a keyword alone returns the result — no mention needed.

### Setup
1. Create a Slack App and prepare scopes, events, and tokens per "Slack Configuration" below.
2. Set your tokens in 【verify: either .env or application.yml — pick one】.
3. Run:
```
mvn spring-boot:run
```
---

### Slack Configuration

#### Bot Token Scopes
- `app_mentions:read` — receive messages that mention the app
- `chat:write` — let the bot send messages
- `im:history` — read DM history so keyword lookups work in DMs

#### App-Level Token (for Socket Mode)
- Issue an App-Level Token (starts with `xapp-`) with `connections:write`, and set it as an environment variable
- Enable Socket Mode

#### Event Subscriptions
- Turn on `Enable Events`
- Subscribe to bot events:
  - `app_mention` — when the bot is mentioned
  - `message.im` — receive messages in DMs with the bot
- Enable App Home > Messages Tab and allow sending from the message tab

## Code Walkthrough 📖

### KeywordLink.java
The entity class. It only holds a keyword and a URL, so instead of Lombok the getters/setters are written by hand.

### KeywordLinkRepository.java
The repository interface. It extends `JpaRepository`, which provides CRUD operations just by extending it.

### LinkcallApplication.java
The entry point generated by Spring Initializr. The app starts from its `main` method.

### SlackConfig.java
Reads the Slack token from the config file and creates the `AppConfig` and `App` beans.

### MentionHandler.java
The event-handling class. It takes `SlackConfig` and the repository, and handles two events: `app_mention` and DMs.

On receiving a mention, it first strips the bot ID with a regex, then splits the text into up to three parts and branches on the first word:

- `register` → instantiates `KeywordLink`, sets the keyword and URL, and saves to H2 via `repository.save()`
- `delete` → looks up by keyword and deletes it if found
- `list` → returns all registered keywords
- otherwise → treats the input as a keyword and returns the URL
- In DMs, a keyword alone returns the result without a mention

# LINKCALL_SLACK_BOT

Slack のメンションで、キーワードに紐づく URL を返す Bot。

> Java Silver 取得後、Spring Boot を学習中。Claude（AI）で生成したコードを動かしながら読み解く形で開発し、各クラスの役割を「コード理解」セクションに自分の言葉でまとめています。

### 背景
Slack を使っていて起きる「あのリンクどこだっけ」を解決するために作成。
ブックマークを探さずに、Slack から直接リンクを呼び出せます。

### 技術スタック
- Java 17
- Spring Boot 【要確認：pom.xml の parent version】
- Slack Bolt SDK (Socket Mode)
- Spring Data JPA / H2 Database (ファイルモード)

> `https://start.spring.io/` でプロジェクト生成後、Slack Bolt を手動追加。
> H2 のファイルモードにより、外部 DB 設定なしでデータを永続化。

### 前提
- Java 17 / Maven
- Slack ワークスペースにアプリを追加できる権限

### 機能
| コマンド | 動作 |
|---|---|
| `@bot 登録 キーワード URL` | URL を登録 |
| `@bot キーワード` | URL を返却 |
| `@bot 削除 キーワード` | 削除 |
| `@bot 一覧` | 登録済み一覧を表示 |

DM では、メンションなしでキーワードだけで結果が返ります。

### セットアップ
1. Slack App を作成し、下記「Slack 設定」に従って権限・イベント・トークンを準備
2. トークンを 【要確認：.env / application.yml のどちらか一方に統一】 に設定
3. 起動：
```
mvn spring-boot:run
```

### Slack 設定

#### Bot Token Scopes
- `app_mentions:read` — アプリがメンションされたメッセージを受け取る
- `chat:write` — Bot がメッセージを送信する
- `im:history` — DM の履歴を読み、DM でのキーワード検索を可能にする

#### App-Level Token（Socket Mode 用）
- `connections:write` を持つ App-Level Token（`xapp-` で始まる）を発行し、環境変数に設定
- Socket Mode を有効化

#### Event Subscriptions
- `Enable Events` をオンにする
- Subscribe to bot events:
  - `app_mention` — Bot がメンションされたとき
  - `message.im` — Bot との DM でメッセージを受け取る
- App Home > Messages Tab をオンにし、メッセージタブからの送信を許可

## コード理解 📖

### KeywordLink.java
Entity クラス。キーワードと URL を保持する変数のみのシンプルな構成のため、Lombok は使わず getter/setter を手書きしています。

### KeywordLinkRepository.java
Repository クラス。`JpaRepository` を継承したインターフェースで、継承するだけで CRUD 操作が使えます。

### LinkcallApplication.java
Spring Initializr が生成するエントリポイント。`main` メソッドからアプリが起動します。

### SlackConfig.java
Slack のトークン情報を設定ファイルから読み込み、`AppConfig` と `App` の Bean を生成します。

### MentionHandler.java
イベント処理クラス。`SlackConfig` と Repository を受け取り、`app_mention` と DM の2つのイベントを処理します。

メンションを受信すると、まず Bot ID を正規表現で除去し、テキストを最大3つに分割。先頭の単語で処理を分岐します。

- `登録` → `KeywordLink` をインスタンス化してキーワードと URL をセットし、`repository.save()` で H2 に保存
- `削除` → キーワードで検索し、見つかれば削除
- `一覧` → 登録済みの全キーワードを返却
- それ以外 → キーワードとして検索し、URL を返却
- DM ではメンションなしでキーワードのみで結果を返却
